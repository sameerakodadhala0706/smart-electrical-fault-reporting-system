# Smart Electrical Fault Reporting, Classification & Tracking System

A web-based B.Tech EEE mini project developed using Base44 AI.

## 🚀 Live Application

https://volt-sense-fix.base44.app

## 📌 Project Description

Smart Electrical Fault Reporting, Classification & Tracking System is a web-based B.Tech EEE mini project developed using Base44 AI. 
It enables users to report electrical faults, classify severity, assign technicians, track repair status, manage maintenance records, 
and analyze fault trends for efficient electrical maintenance.

## ✨ Features

- Electrical fault reporting
- Fault classification
- Severity assessment
- Technician assignment
- Fault status tracking
- Maintenance records
- Electrical fault analytics
- Dashboard
- Notifications
- Preventive maintenance support

## 🛠️ Technology

- Base44 AI
- Web Application
- Database
- AI-assisted development
